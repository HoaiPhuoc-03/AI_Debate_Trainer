# Knowledge Components

`knowledgeHero.js` renders the compact "Kiến thức nền tảng để tranh biện" entry card for the home hub.

The modal lesson is split into lightweight browser components:

- `KnowledgeSlide.js`: slide data and slide markup.
- `KnowledgeProgress.js`: progress bar and dots.
- `KnowledgeNavigation.js`: prev/next controls and slide count.
- `KnowledgeCarousel.js`: keyboard, swipe/drag, state, and slide transitions.
